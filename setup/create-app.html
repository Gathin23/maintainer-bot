Create the maintainer-bot GitHub App

One App, installed only on Gathin23/cleanyourtv. Contents, pull requests and issues write; checks and metadata read; no webhook. Nothing is switched on until the workflow PR is merged.

  1. GitHub shows the App name and permissions; click Create GitHub App for Gathin23.
  2. GitHub sends you back to the cleanyourtv page with ?code=… in the address bar. Copy that code (it works for one hour) and run, in a terminal: 
    ~/Arsenal/maintainer-bot/setup/finish-app.sh THE_CODE
    It turns the code into the App's client ID and private key and stores them straight into the two repository secrets (MAINTAINER_BOT_CLIENT_ID, MAINTAINER_BOT_PRIVATE_KEY). The key is never printed or saved to a file.
  3. Open the install link the script prints, choose Only select repositories → cleanyourtv, Install.
If the button doesn't work: create it by hand

This link opens the form with the same settings filled in. After creating it, copy the Client ID, generate a private key, and run gh secret set MAINTAINER_BOT_CLIENT_ID -R Gathin23/cleanyourtv and gh secret set MAINTAINER_BOT_PRIVATE_KEY -R Gathin23/cleanyourtv < the-key.pem, then delete the downloaded key.
